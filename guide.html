A

概念

每件 Gitskit 都是一次提交。铸造时，合约把一个种子锁定在作品里；贡献图由这个种子确定性地生长出来，永远不会改变。大多数提交干净通过，一些带着冲突，极少数完成了一次合并，并带回一句话。

B

规则

供应 3,232。价格零，平台佣金零。每钱包最多铸造 1 枚，永久有效。铸造需要持有币安 Agent ID，并且只能通过代理完成，合约调用会被拒绝。每次铸造最多填写一位邀请人；自我邀请不计数。

C

$GIT

$GIT 是 Gitskit 的持有者代币，只在 NFT 售罄后开启。领取即焚毁：领取时你的 NFT 被永久销毁，换取 250,000 $GIT（另付一笔小额领取费）。邀请奖励单独领取：每次成功邀请 25,000 $GIT。未领取的 NFT 继续存在；每一次焚毁都会让剩下的作品更稀少。焚毁数量会在本站实时公示。

D

常见问题

为什么没有铸造按钮？
Gitskit 只通过币安智能钱包代理铸造。把首页的提示词发给你的代理即可。

可以铸造第二枚吗？
不可以。每个钱包一枚，由合约强制执行。

邀请人不存在或填错会怎样？
填零地址即可正常铸造，只是不产生邀请记录。邀请记录在铸造时锁定，事后不能更改。
